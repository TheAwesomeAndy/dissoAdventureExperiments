# Reproduction Map: Script to Dissertation Result

This document maps the tables, figures, and statistical results in the ARSPI-Net
dissertation to the scripts that produce them. Results are separated by
inferential status.

- **Confirmatory:** corrected participant-grouped estimates used for the primary
  classification inference.
- **Exploratory:** analyses that generate bounded hypotheses.
- **Archived:** legacy pipelines retained for provenance and replication targets.
  These estimates are descriptive and are not used for the primary inference.

Every indexed result also appears in the machine-readable
[`results_manifest.json`](../results_manifest.json).

Passing verification establishes implementation behavior, not scientific
validity. Inferential tier is determined by design, preprocessing boundaries,
and the estimand, not by unit-test status. See
[`VERIFICATION_METHODOLOGY.md`](VERIFICATION_METHODOLOGY.md).

## Tier 1: Confirmatory classification

### Raw-epoch reconstruction

The committed runner reconstructs each authorized SHAPE epoch from the text
files before feature extraction:

1. remove samples 0 through 204;
2. retain samples 205 through 1228;
3. anti-alias decimate by four to 256 samples;
4. z-score each epoch and channel;
5. exclude Subject 127 from both granularities and Subject 195 additionally from
   the four-category stream.

The resulting cohorts are 211 participants and 633 observations for Negative,
Neutral, and Pleasant, and 210 participants and 840 observations for Threat,
Mutilation, Cute, and Erotic.

### Validation estimator

The protocol uses five repeats of five-fold participant-grouped
`StratifiedGroupKFold`. A participant's complete condition panel stays in one
fold. `StandardScaler` and the linear logistic readout are fitted on training
participants within each fold. BSC6 is compressed from 1,536 to 64 coordinates
with a fixed data-independent `SparseRandomProjection` generated from a
prespecified seed and shared across electrodes.

Balanced-accuracy intervals use a participant-cluster bootstrap over the
out-of-fold predictions pooled from all five repeats. Representation contrasts
use paired participant-cluster bootstrap intervals. A deterministic ridge
readout supplies 100 within-participant label permutations.

All confirmatory rows are generated by
`experiments/confirmatory/run_confirmatory_validation.py`, using
`experiments/confirmatory/confirmatory_pipeline.py`. The runner writes
`confirmatory_results.json`; `check_against_manifest.py` compares every
confirmatory manifest estimand against that file.

### Restricted-data reproduction contract

The repository verifies the participant boundary, raw-epoch preprocessing,
SRP data independence, repeated out-of-fold pooling, bootstrap pairing,
determinism, and destruction operators without distributing SHAPE data. Exact
numerical agreement with the reported estimates must be established by running
the committed pipeline on the authorized dataset and then executing:

```text
python experiments/confirmatory/check_against_manifest.py \
    confirmatory_results.json --tol 1.5
```

The release should include the generated `confirmatory_results.json` or a
checksum-bound restricted-data execution record. Synthetic verification alone
does not establish the reported empirical values.

## Tier 3: Archived results

These analyses use one or more of the following: the archived feature pickle,
globally fitted PCA, complete-panel subject centering, dependent folds, or
legacy input slicing. They are retained for provenance and do not constitute
prospective estimates.
